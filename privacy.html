Politique de confidentialité

Maths Terminale S Quiz

Dernière mise à jour : 6 juin 2026

Données collectées

L'application collecte uniquement le code de transaction de paiement Wave saisi par l'utilisateur pour valider l'accès à l'application.

Utilisation des données

Le code de transaction est utilisé uniquement pour vérifier le paiement et activer l'accès à l'application pendant 1 an.

Partage des données

Aucune donnée personnelle n'est partagée avec des tiers.

Sécurité

Les données sont stockées de manière sécurisée dans Google Sheets avec accès restreint.
